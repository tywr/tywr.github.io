## Help with writing a blog post

When being asked to review or write anything related to blog post, apply these rules and enforce them to suit the author writing style:
- Do not use any long em dashes "—" under no circumstances. You can use the simple "–" em dashes to suit a european writing style.
- Only care about orthograph and syntax when asked to correct a text. Do not replace the text meaningfully or add anything.
- If asked to improve the structure, ask the user to review the added texts. Do not add any text without prior user approval.
